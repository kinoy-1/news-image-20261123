**"The World in One Picture — 23 November 2026."** A newspaper front page
that sums up Monday 23 November 2026 in a single image: a burning planet
Earth bursting out of the torn page — COP31 collapses with no
fossil-fuel deal — above the day's other top stories: Houthi strikes on
a Saudi oil refinery, a Russian drone hitting Kyiv flats, South Korea's
education minister resigning over an AI exam-cheating scandal, and 50
missing after an Indonesian factory fire.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only) copies the pre-rendered `entry.png`
into the output directory. `draw.py` is the build-time renderer (Pillow)
that drew `entry.png`.
